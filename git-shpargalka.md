## Авария А: испортила файл, не коммитила.

**Что случилось:** удалила половину текста в about.md и сохранила, изменения не закоммичены.

половина текста так и была бы удаленной и восстановить ее можно было бы вручную

## Авария Б: в коммит попал лишний файл.

**Что случилось:**

Я создала файл secret.txt записала в него пароль, файл попал в коммит через git add . , но не запушила.

**Как понять, что это оно:**

с помощью git show --stat HEAD я посмотрела содержимое последнего коммита и увидела, что добавлен один файл secret.txt, файл не запушен т.к я не делала git push

**Команда:**

git reset --soft HEAD~1 - я ушла на один коммит назад
и команда отменила последний коммит, но сам файл не трогаю, а оставляю в индексе.

git restore --staged secret.txt. - команда убирает файл из индекса, а в папке он остаётся

.gitignore - git перестаёт видеть сам файл

**Что было бы без неё:**

если бы я запушила файл оказался бы на GitHub, в моем public-репозитории, и его мог бы открыть и прочитать любой человек в интернете
удалить его оттуда просто так нельзя,запушенный коммит не переписывается, даже если потом удалить файл новым коммитом, старый коммит с паролем останется в истории и его можно будет посмотреть
